# STAR DODGE

隕石をよけながら生存時間の自己ベストを目指す、縦画面のブラウザゲームです。HTML / CSS / JavaScript / Canvas 2D のみで動きます。外部ライブラリ、画像、フォント、API、ログインは不要です。既存のブラックジャックとは独立しています。

## 起動

リポジトリのルートで実行します。

```sh
python3 -m http.server 8001 --bind 127.0.0.1
```

通常のローカル開発環境では、ブラウザでポート8001の `/star-dodge/` を開いてください。ビルドも npm install も不要です。UTF-8 の静的ファイルとして配信してください。

## 操作とルール

- **PC:** WASD / 矢印キーで移動。P / Esc / 画面のボタンで一時停止・再開。
- **スマホ:** ゲーム面をドラッグして相対移動。触れた位置への瞬間移動はしません。
- 3秒カウント後に開始。射撃は自動、HPは3、被弾後1.2秒間は無敵です。
- 15秒ごとに SPEED → MULTI → SUB の強化アイテムが流れます。触れて取得すると強化されます。上限の種類は飛ばします。
- 隕石の量・HPは時間とともに増加します。画面下へ逃してもペナルティはありません。
- HP0で終了。生存時間のみが主記録で、破壊数は参考情報です。制限時間、得点競争、回復、恒久強化はありません。
- サウンドは初期オフ。SOUND ボタンで変更できます。ユーザー操作後のみ Web Audio で短い効果音を再生します。
- タブ離脱・フォーカス喪失時に自動停止します。戻った後は明示的な再開が必要です。
- 自己ベスト・直近の生存時間・サウンド設定を localStorage の `star-dodge-v1` に保存します。利用不能時はタブ内に保持し、通知を表示します。

## ファイルと調整

- `engine.js`: ブラウザに依存しないシミュレーション、記録保存。`Game` の `random` 引数へ乱数関数を渡せます。
- `app.js`: Canvas 描画、画面状態、キーボード・Pointer Events、Web Audio。
- `style.css` / `index.html`: PC・スマホ向け画面。
- `engine.test.cjs`: Node 標準テストランナーの自動テスト。
- `browser.test.cjs`: Playwright による実ブラウザ検証。

`engine.js` の `CONFIG` に調整値を集約しています。`player` はHP・速度・当たり判定・無敵、`main` は射撃間隔・弾速・角度（配列の長さが各レベルの弾数）、`sub` はドローン射撃、`items` は出現間隔・落下速度、`rocks` はHP・割合・出現間隔・同時数・速度・間隔の上限を管理します。UIの弾速・弾数上限もこの設定から表示します。

論理座標は480×720、更新は1/60秒固定です。1フレームで受け取る時間は最大0.1秒です。カウント・停止時間は記録に加算しません。高速弾は移動区間で衝突判定し、相対的な隕石の移動も考慮します。描画サイズの変更で論理座標は変わりません。演出粒子は最大180個、隕石は最大80個です。動きを減らす設定では装飾的な点滅・粒子・星のスクロールを抑制します。

## 検証

ルートから、追加パッケージ不要で実行できます。

```sh
node --test star-dodge/engine.test.cjs
```

23テストが成功しました。時間・射撃間隔、移動の正規化、30/60/120fps同等性、長い停止の制限、難化と各隕石種、最大80個と同時出現間隔、15秒ごとの強化順と135秒での最大強化、ドローン、高速弾衝突、無敵時間、致命傷と取得の順、結果後の停止、再挑戦、記録更新・同値・破損・保存拒否を確認しています。

ブラウザテストは Playwright と Chromium を別途用意し、HTTPサーバーを起動してから実行します。ゲーム本体の依存ではありません。テスト用依存をチェックアウト外へ入れる例:

```sh
npm install --prefix /tmp/star-dodge-browser --no-save playwright
NODE_PATH=/tmp/star-dodge-browser/node_modules node star-dodge/browser.test.cjs
```

既定の Chromium は `/usr/bin/chromium`。`CHROMIUM_PATH` で変更できます。テストの配信先は `STAR_DODGE_URL`、スクリーンショット保存先は `STAR_DODGE_ARTIFACTS` で変更できます。既定の画像出力先は `/tmp/star-dodge-checks` です。

Chromium（Playwright 1.62.1、ヘッドレス）でPC 1440×1000とスマホ相当390×844の画面を検証しました。キーボード・タッチドラッグ、開始カウント中の中断、P/Esc、フォーカス喪失、強化表示、被弾から結果画面、再挑戦、再読み込み後の記録・音設定、保存拒否時の起動が成功しました。結果画面の確認にはテスト内で制御した隕石配置を使用しています。JavaScript例外と外部リクエストは0件でした。

実機のAndroid/iPhone、Safari・Edge、実際の音の聞こえ方、遊び続けた際の難易度・面白さは未確認です。音のユーザー操作制限と無音設定は実装済みですが、聴覚的な評価は行っていません。公開URLの動作確認も未実施です。

## 静的公開

このフォルダー全体を静的ホスティングへ配置できます。リポジトリルートを配信する構成では `/star-dodge/` がゲームの入口です。既存の GitHub Pages と同じルートを配信する場合も、ブラックジャックの `index.html` を置換する必要はありません。
