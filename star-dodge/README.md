# STAR DODGE 0.2.1 — パイロット育成版

隕石をよけて生存記録を伸ばし、フライト報酬で機体と初期スキルを育てるブラウザゲームです。ブラックジャックとは独立しています。

## 今回遊べるもの

- ホームから機体ハンガー、初期スキル、チャレンジ、アカウント、ショップへ移動。
- 3種類の機体。パイオニア（HP3 / 速度300）、スウィフト（HP2 / 345）、ウォーデン（HP4 / 270）。解放はプレイで獲得するコインのみ。
- 装甲（HP+1、2段階）、初期弾速（2段階）、初期弾数（2発化）、初期ドローンを恒久強化。次のフライトから適用。
- 報酬は5秒ごとに1コインに加え、30秒到達で4、60秒到達で6、以降30秒ごとに8コインの追加ボーナス。破壊5個で1コインを加算しますが、生存・到達報酬の20%（切り捨て）まで。合計は1回最大500コイン。終了時に一度だけ付与し、放棄・最初からでは付与しません。
- 達成報酬つきのチャレンジ5つ。受取は一度だけ。連続ログインの強制や有料ガチャはありません。
- 480×720、固定1/60秒の自動射撃サバイバル。3秒カウント、時間による隕石の増加・硬化、15秒ごとのアイテム、被弾後の無敵、結果・再挑戦。
- サウンド初期オフ。タブ離脱・フォーカス喪失時は自動停止し、明示的な再開を待ちます。
- ブラウザへのインストールと、初回オンライン読み込み後のオフライン起動（PWA）。対応状況はブラウザに依存します。

## 起動・操作

リポジトリルートから実行:

```sh
python3 -m http.server 8001 --bind 127.0.0.1
```

ブラウザで配信ポートの `/star-dodge/` を開きます。ブラウザ版のビルドや npm install は不要です。PCはWASD / 矢印キー、スマホは相対ドラッグ。射撃は自動、P / Escで停止・再開。

公開対象: <https://chani0422.github.io/My-Games/star-dodge/>

PWA更新時は `sw.js` のキャッシュ名・キャッシュ取得URLのバージョンと、HTMLのCSS/JS参照の `v` を合わせて更新してください。飛行中のバージョンを維持するため、自動的な強制更新はしません。更新が見えなければゲームのタブをすべて閉じて開き直してください。

報酬設計の比較・具体例は [コインバランス](docs/ECONOMY.md) を参照してください。

## 保存とログイン

ゲストでの育成はこのブラウザの `star-dodge-progress-v1`、記録・サウンドは既存の `star-dodge-v1` に保存します。旧版の記録を保持します。保存できない場合はタブ内に保持して通知します。コインはローカルのプレイ報酬であり、有料通貨ではありません。

Supabase 接続用のメール確認コード認証、手動クラウド保存・内容確認後の復元、ログアウト、アカウント削除の処理を実装しています。`config.js` のURL・公開キーは未設定で、公開版のログインは「準備中」です。設定前にメールやコードを送信しません。接続後も自動上書きはしません。ログインセッションはこのタブで維持します。

実際の認証・DB・削除Functionの導入方法は [公開・接続ガイド](docs/RELEASE.md)。サービスのURLとpublishable/anon公開キー以外を `config.js` に書かないでください。service_roleキーはサーバー専用です。

## 広告・課金

`services.js` の `Monetization` に、広告プロバイダー、課金プロバイダー、サーバー検証を分けた接続口があります。未接続では必ず unavailable を返します。キャンセルや未検証の結果に報酬を付与しません。ショップと結果画面の動画ボタンは「準備中」で、実際の広告・支払い・有料報酬の付与はありません。

本番導入には、AdMob等のSDK、Google Play Billing、サーバー側の購入検証・広告完了通知・重複防止・権利管理が必要です。現在のローカルコインを有料残高として扱うことはできません。詳細は公開ガイドに記載しています。

## 構成と調整

| ファイル                         | 役割                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------- |
| `engine.js`                      | 描画と独立したシミュレーション。`CONFIG` に難易度・速度・射撃・当たり判定などを集約      |
| `progression.js`                 | `SHIPS`、`UPGRADES`、`MISSIONS`、報酬・育成保存                                          |
| `services.js` / `config.js`      | Supabase REST接続と広告・課金の接続口、公開設定                                          |
| `app.js`                         | ホームと各画面、描画、入力、効果音、Androidのバックグラウンド・戻る操作                  |
| `sw.js` / `manifest.webmanifest` | オフラインキャッシュ、インストール情報                                                   |
| `backend/`                       | 所有者のみアクセスできるSupabase RLS付きテーブル、認証済みユーザー自身を削除するFunction |
| `mobile/`                        | Androidアプリ用のプロジェクト。`www`・生成されたWebアセットはGit管理対象外               |

強化は `Game.start(loadout)` で適用します。飛行中の育成変更は次の開始まで反映しません。初期強化後も飛行中アイテムの上限は同じです。乱数は `new Game({random})` で差し替えられます。

## 検証

```sh
node --test star-dodge/engine.test.cjs star-dodge/progression.test.cjs star-dodge/economy.test.cjs star-dodge/services.test.cjs
```

43テスト成功。元の時間進行・難化・移動・衝突・再挑戦・保存に加え、報酬の一度だけの精算、強化コストと上限、機体の実際のHP・移動速度、初期スキル適用、チャレンジ、育成の復元、認証リクエスト・更新・本人確認、広告キャンセル・購入検証の接続口を確認しています。

PlaywrightとChromiumを用意し、HTTPサーバー起動後:

```sh
node star-dodge/browser.test.cjs
node star-dodge/hub.browser.test.cjs
```

テスト用Playwrightはゲーム本体の依存ではありません。必要ならチェックアウト外へインストールできます。

```sh
npm install --prefix /tmp/star-dodge-browser --no-save playwright
NODE_PATH=/tmp/star-dodge-browser/node_modules node star-dodge/hub.browser.test.cjs
```

既定のブラウザは `/usr/bin/chromium`。`CHROMIUM_PATH` と `STAR_DODGE_URL` で変更できます。

ChromiumのPC・スマホ相当画面で、キーボード・タッチ、停止、フォーカス喪失、終了・再挑戦、ホームの機体解放・強化・報酬受取・再読み込み後の保持、保存拒否時の起動、オフライン再読み込みを確認済み。Supabaseのフォーム・保存・復元・削除フローはモック接続で確認済みです。

実際のSupabaseプロジェクト、SMTP、RLSポリシーの実行、Edge Function、本番広告・課金、Android/iPhone実機、Safari/Edge、音の聴覚評価、育成後の難易度バランスは未検証です。動作確認と、面白さ・継続率の検証は別です。
