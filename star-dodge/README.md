# STAR DODGE 0.5.0 — 4つの弾種・8惑星40ステージ・強化コア3択

40ステージの設計と検証は [8惑星・40ステージ](docs/STAGES.md)、変更の報告は [PR-B実装報告](docs/PLANETS_40.md)、4機体への再編は [4機体とセーブ移行](docs/FOUR_SHIPS.md) を参照してください。公開番号は0.5.0 / versionCode 5を維持します。音量・図鑑までの実装履歴は [実装報告書](docs/IMPLEMENTATION_0_5.md) に記載しています。

隕石をよけて生存記録を伸ばし、ステージのクリアで機体を解放し、フライト報酬で初期スキルを育てるブラウザゲームです。ブラックジャックとは独立しています。

## 今回遊べるもの

- 地球から海王星まで8惑星・全40ステージ。最初の30秒は出現フェーズで、その後に残った隕石をすべて破壊するとクリア。殲滅中は新規出現が止まり、下へ抜けた隕石はHPを維持して上から再出現します。衝突やシールド防御でも隕石は残り、射撃による撃破が必要です。ホームの「惑星 → 5ステージ」で選択し、順番に解放。クリア後は次へ進む/最終ステージは再挑戦。従来のエンドレスも選べます。ステージ別に隕石の速度・間隔・硬さ・同時数が上がり、初回クリアは5〜83コインの追加報酬（各1回だけ）。
- 機体の被弾判定を半径10→6へ変更。全機体の中央に判定と一致する円を常時表示（通常は白、無敵中は黄）。アイテム取得範囲と移動範囲は以前のままです。

- ホームから機体ハンガー、初期スキル、スキル図鑑、チャレンジ、アカウント、スキンショップ、ライセンス、フライト記録、遊び方・設定へ移動。
- 6種類のカラーを実装。4種類は80〜200コインで解放、初期カラーとランク3のオーロラは無料。どの機体にも使え、性能・当たり判定は変わりません。選択は保存され、次回開始時に反映。
- 累計生存時間によるランク1〜20のライセンス。累計4分でランク3に到達。連続ログインは要求しません。
- 最近20回の結果、使用機体・カラー・開始/終了スキル、累計/平均時間を表示。匿名の記録JSONを書き出せます（Android内では選択・コピー用に表示）。ユーザー操作による結果共有はシステム共有→コピー→選択可能な文章の順に対応。
- 4種類の機体。通常弾のパイオニア、貫通弾のランス、撃破時に爆発するノヴァ、誘導弾のシーカー。全機体の基礎HPは3、移動速度は毎秒300で共通。装甲の初期強化は全機体へ同じように加算します。ランス/ノヴァ/シーカーはステージ5/15/25クリアで解放し、機体のコイン購入はありません。5/15/25は地球/金星/木星のステージ5です。解放時は結果画面に通知し、ハンガーで選べます。
- 弾種の特性はメイン弾だけに適用し、ドローン弾は全機体で従来の通常弾です。貫通は弾速85%、爆発は発射間隔115%、誘導は弾速90%を仮の弱点とし、試遊で調整します。
- 装甲（HP+1、2段階）、初期弾速（2段階）、初期弾数（2発化）、初期ドローンを恒久強化。次のフライトから適用。
- 報酬は5秒ごとに1コインに加え、30秒到達で4、60秒到達で6、以降30秒ごとに8コインの追加ボーナス。破壊5個で1コインを加算しますが、生存・到達報酬の20%（切り捨て）まで。ステージ初回クリアも含め合計は1回最大500コイン。殲滅を含むゲーム内の生存時間で計算し、終了時に一度だけ付与します。放棄・最初からでは付与しません。
- 蛇行・予告付き突進・射撃する敵。ステージ15秒のラッシュ/エリートと、連続撃破コンボ。隕石と敵弾・エフェクトは上限管理。
- スキル図鑑はフライト中の8種を火力/移動・収集/防御・回復に分類。3択と同じアイコン・名前・説明・色と最大レベルを表示し、初期強化4種の所持レベルも確認できます。閲覧専用で、購入は従来の画面から行います。
- コアで連射・威力・拡散・弾速・ドローン・シールド・マグネット・修理を選択。選択中は時間・敵・弾が止まり、タップ/1–3/矢印＋Enterに対応。強化はその回のみで、全上限時の余剰コアは+2コイン（総報酬500まで）。
- 恒久強化で装甲パーツ・弾トレイル・ドローン外見も解放。ハンガーのプレビューで確認できます。
- 達成報酬つきのチャレンジ5つ。受取は一度だけ。連続ログインの強制や有料ガチャはありません。
- 480×720、固定1/60秒の自動射撃サバイバル。3秒カウント、ステージ進行/エンドレスの時間経過による隕石の増加・硬化、12秒ごとの強化コア（ステージは最初の30秒のみ）と停止中の最大3択、被弾後の無敵、結果・再挑戦。
- 演出を控えめにする設定を保存。端末の視差効果軽減設定も優先し、ゲーム進行や当たり判定は変わりません。
- Web Audio合成のBGMと射撃/命中/撃破/コア/選択/被弾/クリア/UI効果音。遊び方・設定から音量0〜100%を調整し、SOUND ON/OFFとは独立して保存。全員の設定を一度ONへ移行し、以後のOFFは保持。最初の操作後に音が始まります。タブ離脱・フォーカス喪失時は自動停止し、明示的な再開を待ちます。
- ブラウザへのインストールと、初回オンライン読み込み後のオフライン起動（PWA）。対応状況はブラウザに依存します。

## 起動・操作

リポジトリルートから実行:

```sh
python3 -m http.server 8001 --bind 127.0.0.1
```

ブラウザで配信ポートの `/star-dodge/` を開きます。ブラウザ版のビルドや npm install は不要です。PCはWASD / 矢印キー、スマホは相対ドラッグ。射撃は自動、P / Escで停止・再開。

公開対象: <https://chani0422.github.io/My-Games/star-dodge/>

画面下部に `VERSION 0.5.0` を表示し、ホーム/結果画面から「最新版を確認」できます。オンラインでは新しいHTMLを優先し、オフラインでは同じ版のHTMLとスクリプト一式を使います。新しいワーカーは待機状態に残し続けず有効化しますが、飛行中の画面を強制再読み込みしません。新しいバージョンのJS要求に古いキャッシュを返すことも避けています。旧0.3以前の画面が残る場合は、ゲームのタブ/PWAをすべて閉じて開き直すか、再読み込み後に数秒待ってもう一度再読み込みしてください。保存データの削除は不要です。APK版はWebとは別で、新版APKへの上書き更新が必要です。

次の更新では `version.json`、`sw.js` のVERSION/キャッシュ名、app.jsのAPP_VERSION、HTMLのCSS/JS参照とフッター、Android版のバージョンを合わせて更新してください。

40ステージ対応のキャッシュ識別子は `star-dodge-shell-v0-5-0-planets-40`。公開番号は0.5.0 / versionCode 5を維持します。既存の同版キャッシュにも更新が届くようワーカーのキャッシュだけ区別し、プレイ中の画面は強制再読み込みしません。

ステージの数値とクリア仕様は [40ステージの設計](docs/STAGES.md) を参照してください。

報酬設計の比較・具体例は [コインバランス](docs/ECONOMY.md) を参照してください。

## 保存とログイン

ゲストでの育成はこのブラウザの `star-dodge-progress-v1`、スキン・ランク・最近のフライト・演出設定・ステージ解放/選択も同じキーに保存し、記録・サウンドON/OFF・音量は既存の `star-dodge-v1` に保存します。旧版の記録を保持します。保存できない場合はタブ内に保持して通知します。コインはローカルのプレイ報酬であり、有料通貨ではありません。

旧機体の購入済みコインはスウィフト120、ウォーデン140を各1回だけ返金します。旧機体の選択はパイオニアへ戻し、購入済みIDを保存から除くことで再読み込み時の重複返金を防ぎます。コイン・初期強化・スキン・ライセンス・累計/直近記録・ステージ番号は引き継ぎます。移行は同じ保存キー・version 1・既存フィールドで行います。

音量は `volume`（0〜1）だけを `star-dodge-v1` に追加します。旧セーブは1（100%）から開始し、不正値は1、範囲外の数値は0〜1へ丸めます。`star-dodge-progress-v1` の項目やクラウド保存対象は変えません。初期マスターゲインを0.6から0.9へ上げた意図と、カテゴリ別の色・検証内容は [音量とスキル図鑑](docs/AUDIO_AND_SKILLS.md) を参照してください。

Supabase 接続用のメール確認コード認証、手動クラウド保存・内容確認後の復元、ログアウト、アカウント削除の処理を実装しています。`config.js` のURL・公開キーは未設定で、公開版のログインは「準備中」です。設定前にメールやコードを送信しません。接続後も自動上書きはしません。ログインセッションはこのタブで維持します。

実際の認証・DB・削除Functionの導入方法は [公開・接続ガイド](docs/RELEASE.md)。サービスのURLとpublishable/anon公開キー以外を `config.js` に書かないでください。service_roleキーはサーバー専用です。

## 広告・課金

`services.js` の `Monetization` に、広告プロバイダー、課金プロバイダー、サーバー検証を分けた接続口があります。未接続では必ず unavailable を返します。キャンセルや未検証の結果に報酬を付与しません。実際のコイン用スキンショップとは別に、プレミアム商品と結果画面の動画ボタンは「準備中」で、実際の広告・支払い・有料報酬の付与はありません。

本番導入には、AdMob等のSDK、Google Play Billing、サーバー側の購入検証・広告完了通知・重複防止・権利管理が必要です。現在のローカルコインを有料残高として扱うことはできません。詳細は公開ガイドに記載しています。

## 構成と調整

| ファイル                         | 役割                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------- |
| `audio.js` / `effects.js`        | 上限付き合成BGM・効果音、プール管理する視覚演出 |

| `services.js` / `config.js`      | Supabase REST接続と広告・課金の接続口、公開設定                                          |
| `app.js`                         | ホームと各画面、描画、入力、効果音、Androidのバックグラウンド・戻る操作                  |
| `sw.js` / `manifest.webmanifest` | オフラインキャッシュ、インストール情報                                                   |
| `backend/`                       | 所有者のみアクセスできるSupabase RLS付きテーブル、認証済みユーザー自身を削除するFunction |

強化は `Game.start(loadout)` で適用します。飛行中の育成変更は次の開始まで反映しません。飛行中の3択は `Game.skills`・`levels`・`shield` にのみ保持し、恒久セーブへ保存しません。乱数は `new Game({random})` で差し替えられます。
