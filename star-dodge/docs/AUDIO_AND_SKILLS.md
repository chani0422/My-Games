# 音量調整とスキル図鑑（0.5.0）

公開番号は0.5.0 / versionCode 5を維持します。アプリIDと署名設定も変更しません。

## 音量

ホームの「遊び方・設定」からマスター音量を0〜100%で調整できます。ドラッグ中の `input` でゲインと表示と保存を即座に更新し、`change` で操作が確定したときだけ確認用のUI音を1回要求します。SOUND OFF中は確認音を鳴らさず、音量値は保持します。0%にしてもSOUNDのON/OFF設定は変えません。

音声のマスターゲインは `0.9 × volume`。従来の固定0.6から、初期状態は0.9へ上がります。「音が小さい」という試遊所見に対応する意図的な変更です。BGMと効果音の相対バランス、音源・ボイス上限・停止処理は維持します。

保存先 `star-dodge-v1` に `volume` を1項目だけ追加します。数値の0〜1を許容し、負数は0、1を超える数値は1へ丸めます。未設定・不正な型・非有限数は1を使います。旧ユーザーも音量は1から開始し、既存の記録とSOUND設定の移行規則は維持します。保存できない場合は従来どおりタブ内で保持します。

`star-dodge-progress-v1` のフィールド、コイン、価格、初期強化、ステージ解放、クラウド保存・復元対象は変更しません。音量はSOUNDと同様、端末内の設定です。

## 共通のスキル定義

`engine.js` の `FLIGHT_CATEGORIES` と `FLIGHT_UPGRADES` を参照し、3択と図鑑は同じ名前・アイコン・説明・上限・色を使います。色の対応表をUI側へ重複させません。

| 火力 | damage | #ff8562 |

3択の枠とアイコン、図鑑の枠とアイコンにこの色を反映します。全上限時の「余剰コア」は9種の一覧には追加せず、従来の金色 #ffd47dを維持します。スキルの効果や抽選・選択・強化上限は変えません。

## 閲覧専用の図鑑

ホームから「スキル図鑑」を開き、フライト中スキル9種を火力・移動・防御/回復の見出しで確認できます。PCでは2列、スマホでは1列に並びます。色だけに依存せず、カテゴリ名とスキル名も表示します。

「初期スキル強化」には `progression.js` の既存4種の名前・説明・現在の所持レベルを表示します。購入や選択の操作は置かず、従来の初期強化画面を使います。図鑑の閲覧でコインや育成データを変更しません。

## 更新と検証

ワーカーのキャッシュ名を `star-dodge-shell-v0-5-0-volume-skills` に変更します。VERSION、APP_VERSION、HTMLの参照番号、AndroidのversionName/versionCodeは据え置きです。プレイ中に強制再読み込みはせず、同じ0.5.0の古いキャッシュからも新しい一式へ移行できます。

Nodeは既存86件と追加7件（保存4・ゲイン2・カテゴリ色1）の93件。`engine.test.cjs` の既定レコードの期待値にvolume:1を追加し、更新試験のキャッシュ名を変更します。既存の色の期待値を差し替えるテストはなく、新しいパレットを追加検証します。

`settings.browser.test.cjs` は1440×1000、390×844、360×640で、スライダーと実ゲイン、確認音1回、OFFと再読み込み、説明・色・所持レベルの一致、閲覧専用、余剰コアの金色を確認します。既存のブラウザ試験も維持します。Androidへは `cd star-dodge/mobile && npm run sync` で同期します。実施結果はPR本文に記載します。
