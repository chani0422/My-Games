# 音量調整とスキル図鑑（0.5.0）

公開番号は0.5.0 / versionCode 5を維持します。アプリIDと署名設定も変更しません。

## 音量

ホームの「遊び方・設定」からマスター音量を0〜100%で調整できます。ドラッグ中の `input` でゲインと表示と保存を即座に更新し、`change` で操作が確定したときだけ確認用のUI音を1回要求します。SOUND OFF中は確認音を鳴らさず、音量値は保持します。0%にしてもSOUNDのON/OFF設定は変えません。

現行のマスターゲインは `1.0 × volume`、各音のエンベロープゲインは従来の2.5倍です。BGMの各パートと既存効果音に共通の倍率を掛け、音同士の基準バランスを維持します。マスターの後にDynamicsCompressor（threshold -10dB、knee 6dB、ratio 12、attack 3ms、release 160ms）、自動音量補正を抑えて余裕を確保する固定出力ゲイン0.6を接続します。Chromiumの実音声レンダリングでは、旧 `0.9 × volume` 版比でBGMのRMSが2.66〜2.67倍、既存効果音が2.74倍でした。重なり時の圧縮により、すべての瞬間で同一倍率になるわけではありません。

音源・同時ボイス上限24（SFX最大16）・停止処理は維持します。固定ノードがマスター1個からマスター/コンプレッサー/出力の3個になるため、最大ノード数の期待値は49から51へ変更します。音量測定とノヴァ専用の爆発音については [調整報告](NOVA_AND_AUDIO.md) を参照してください。

保存先 `star-dodge-v1` の既存 `volume` をそのまま使います。今回、保存形式への項目追加はありません。数値の0〜1を許容し、負数は0、1を超える数値は1へ丸めます。未設定・不正な型・非有限数は1を使います。旧ユーザーも音量は1から開始し、既存の記録とSOUND設定の移行規則は維持します。保存できない場合は従来どおりタブ内で保持します。

`star-dodge-progress-v1` のフィールド、コイン、価格、初期強化、ステージ解放、クラウド保存・復元対象は変更しません。音量はSOUNDと同様、端末内の設定です。

## 共通のスキル定義

`engine.js` の `FLIGHT_CATEGORIES` と `FLIGHT_UPGRADES` を参照し、3択と図鑑は同じ名前・アイコン・説明・上限・色を使います。色の対応表をUI側へ重複させません。

| カテゴリ | スキルID | 色 |
| --- | --- | --- |
| 火力 | rapid | #ff6f61 |
| 火力 | damage | #ff8562 |
| 火力 | multi | #ff5f7a |
| 火力 | speed（弾速） | #ffa25e |
| 火力 | sub | #ff6f91 |
| 移動・収集 | magnet | #6be0ff |
| 防御・回復 | shield | #91d7ff |
| 防御・回復 | repair | #a5ffba |

3択の枠とアイコン、図鑑の枠とアイコンにこの色を反映します。全上限時の「余剰コア」は8種の一覧には追加せず、従来の金色 #ffd47dを維持します。機動ブースト（movement）は候補・図鑑・結果表示から削除し、移動速度を毎秒300へ固定します。マグネットは移動・収集に残します。残る8種の効果・選択・強化上限は維持します。

## 閲覧専用の図鑑

ホームから「スキル図鑑」を開き、フライト中スキル8種を「火力」「移動・収集」「防御・回復」の見出しで確認できます。PCでは2列、スマホでは1列に並びます。色だけに依存せず、カテゴリ名とスキル名も表示します。

「初期スキル強化」には `progression.js` の既存4種の名前・説明・現在の所持レベルを表示します。購入や選択の操作は置かず、従来の初期強化画面を使います。図鑑の閲覧でコインや育成データを変更しません。

## 更新と検証

現在のキャッシュ名は、ノヴァ・音量調整の `star-dodge-shell-v0-5-0-nova-audio` です。VERSION、APP_VERSION、HTMLの参照番号、AndroidのversionName/versionCodeは据え置きです。プレイ中に強制再読み込みはせず、同じ0.5.0の古いキャッシュからも新しい一式へ移行できます。

音量・図鑑の導入時点は既存86件と追加7件（保存4・ゲイン2・カテゴリ色1）の93件でした。PR-Aでは機動削除と8種への変更に合わせて既存試験を書き換え、4機体・解放・返金移行の試験を追加します。最終結果はPR本文に記載します。`engine.test.cjs` の既定レコードの期待値にvolume:1を追加し、更新試験のキャッシュ名を変更します。既存の色の期待値を差し替えるテストはなく、新しいパレットを追加検証します。

`settings.browser.test.cjs` は1440×1000、390×844、360×640で、スライダーと実ゲイン、確認音1回、OFFと再読み込み、説明・色・所持レベルの一致、閲覧専用、余剰コアの金色を確認します。既存のブラウザ試験も維持します。Androidへは `cd star-dodge/mobile && npm run sync` で同期します。実施結果はPR本文に記載します。
