# STAR DODGE 0.5向け改良 実装報告書

実装指示書（2026-10-29）に基づくレビュー用の変更です。基点は `origin/main` の `4a959f2`。実装ブランチは `feat/star-dodge-0-5`。mainへの直接push・公開は行いません。

このPRでは公開番号の更新を含めません。画面/APP_VERSION/version.json/SW/Androidは0.4.0、versionCode 4のままです。正式アプリID `com.chani0422.stardodge` と署名設定も変更していません。以下の機能は、この実装ブランチのものです。

## 1. 音

- 音源ファイルなしのWeb Audio合成BGM。ベースとアルペジオを112 BPMでループし、ステージ7以降と山場で音色・音数を追加。
- 射撃/命中/サイズ別撃破/被弾/シールド/コア取得/3択決定/ゲームオーバー/クリア/UI操作を合成。射撃・命中は間引き、低音量。撃破の音程はコンボで緩やかに上昇。
- 最大24ボイス。オシレーター+Gainのノードはmasterを含め最大49（AudioDestinationを除く）。停止/終了時に切断し、発音スケジューラーも停止。
- ポーズ・タブ/ウィンドウ離脱・Androidバックグラウンドは停止。コア選択中はBGMを停止し、取得音は最後まで再生。
- 全員の初期設定を一度ONへ移行。ブラウザの自動再生制約に従い最初のユーザー操作から開始。以後OFFにした場合は再読み込みでも保持。

## 2. 敵と山場

- 蛇行、0.5秒の照準予告後の突進、2.5秒ごとに1発撃つ射撃敵を追加。敵弾は速度125・半径3で、自機半径6との連続判定を使います。
- ステージは1–2/3以降/5以降、エンドレスは30/60/90秒で段階解放。
- 15秒の山場は奇数ステージがラッシュ、偶数がエリート。エンドレスは60秒ごとに交互。バナー・専用色・枠を表示し、エリート撃破は確定コア。
- 元のステージ数値を維持。ラッシュは5秒だけ出現間隔0.8倍（最短0.22秒）。新規出現は機体近くの経路を避けます。特殊敵も隕石の上限80に含め、射撃敵も追加の敵枠として無制限には増えません。
- 横移動する敵にも弾の連続衝突判定を拡張。固定1/60秒・random差し替えを維持し、30/60/120fpsで結果一致を検証。

## 3. 強化と見た目

- 定期コアは12秒ごと。機体の近くから追従し、ステージ内で12秒/24秒付近の2回選べるよう設計。エリートのコアは倒した場所から、吸引範囲に入ると追従。
- 9系統: 連射、弾ダメージ、拡散、弾速、ドローン/ドローン威力、シールド、移動速度、マグネット、修理。
- コア取得で敵・弾・時間を完全停止。タップ、数字1–3、矢印+Enterで決定。選択中にポーズ/離脱した場合、再開先も選択画面です。
- 上限済み・HP満タンの修理を除外。通常は3枚、候補が1–2種類ならその枚数、全上限なら余剰コア+2コインの1枚。無効な水増し候補は表示しません。
- 飛行中の強化は開始時にリセットし、恒久プロフィールには保存しません。
- 恒久装甲で外付け装甲、恒久弾速でトレイル、恒久ドローンで形/色を変化。既存の段数から導出し、ハンガーのSVGプレビューにも表示。外見による追加の当たり判定変更はありません。

## 4. 演出

- 小隕石14〜大隕石36の火花/粒子と拡大リング、命中60msの白い閃光。
- 被弾時6、巨大隕石撃破時2.8を上限とする短いシェイク。HUDやページのレイアウトは揺らさず、選択/ポーズ/結果中は揺れを止めます。
- 浮くダメージ数字を再利用プールで管理。3秒以内の連続撃破コンボを表示。
- reduceEffectsまたは端末の視差軽減で、粒子・リング・数字・シェイク・閃光・トレイルの動きを抑制。判定円・予告線・コンボの静的情報は残します。

| 敵弾 | 48 |
| 自機/ドローン弾 | 192 |

## スコープと経済

削った柱・敵・数字演出はありません。機体3種類、カラー6種類、ステージ10、最近20件は維持。ログイン必須、オンラインランキング、広告配信、ガチャ、追加の外部通信、音源ファイルは追加していません。

基本報酬・初回クリア・強化価格は維持。全強化上限の余剰コアだけ+2を追加し、終了時に精算、全体500の上限を維持。コンボの報酬増はありません。[ECONOMY.md](ECONOMY.md) に再計算と上限を記載しました。

## 保存互換性

`star-dodge-progress-v1` のスキーマ・フィールドは変更せず、外見は既存強化から計算。0.4コードから生成した合成セーブfixtureについて、コイン・解放・ステージ・全20件・他の全項目が完全一致すること、クラウド復元相当のrestoreも一致することを確認します。試験データは実ユーザーデータではありません。

`star-dodge-v1` はbest/last/soundを維持し、`soundDefaultRevision: 1` のみ追加。旧設定のON移行を1回に限定するための印です。移行後のOFF保存/再読み込みも検証します。
