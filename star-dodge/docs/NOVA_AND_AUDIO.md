# ノヴァ強化と音量の調整報告（0.5.0 / 2026-11-04）

マージ済みのmain `84dea14`（PR #7）から `fix/star-dodge-nova-audio` を作成しました。公開番号0.5.0 / versionCode 5、アプリID `com.chani0422.stardodge`、署名設定は維持します。

## 実装

ノヴァの爆発半径を70から120へ広げ、爆発の威力を「撃破した弾のダメージ、上限3」へ変更しました。弾が飛んだ後のスキル値ではなく、その弾が保持するダメージを使うため、威力スキルの効果を反映します。中心間の距離で半径の境界を判定します。

直撃撃破からの爆発を深さ0とし、そこで倒した各隕石は深さ1の二次爆発を起こします。深さ1で倒れた隕石は爆発しません。最初の爆発のダメージ処理が終わってから二次爆発を処理し、同じ個体を繰り返し起爆しません。各爆発の威力は最大3で、複数の爆発が重なればそれぞれ命中します。撃破数・コンボ・エリートのコアは従来の撃破処理を使い、同じ隕石から重複付与しません。

ドローン弾は通常弾のままで、爆発しません。発射間隔115%の弱点、通常の直撃ダメージ、初期強化・3択の定義は維持します。

爆発リングは最大半径120まで広がり、表示時間を0.3秒から0.6秒へ延ばし、線を太くしました。1回の爆発につき42個の粒子を追加し、短いシェイクを付けます。粒子180・リング12の既存プール上限は維持します。「演出を控えめにする」ではリング・粒子・シェイクを無効にし、ダメージと連鎖は同じです。

爆発音は通常の撃破音の流用をやめ、低音の0.36秒の響きと0.09秒の短い高音を重ねる専用音へ変更しました。連鎖時に重なりすぎないよう100ms間隔で鳴らし、既存のSFX最大16・全体24ボイス上限を維持します。

## 音量とクリッピング

BGM各パートと既存効果音のエンベロープ全体を共通に2.5倍にし、マスターを `1.0 × volume` へ変更します。基準の相対バランスは維持します。マスターの後段にDynamicsCompressor（threshold -10dB、knee 6dB、ratio 12、attack 3ms、release 160ms）を置き、圧縮器の自動音量補正を抑えて余裕を確保する固定出力ゲイン0.6を接続します。大きな重なりでは圧縮が働くので、全瞬間で同じ倍率にはなりません。

`star-dodge-v1` の既存 `volume`（0〜1）、SOUND ON/OFF、スライダーの保存・即時反映・確認音の操作は変えません。固定ノードが2個増えるため、24ボイス時の最大ノード期待値は49から51へ変更します。Web Audioの停止・フォーカス離脱・OFFの処理は維持します。

Chromiumの実際のOfflineAudioContextで、48kHz・モノラル・4秒を旧mainと比較しました。RMSはデジタル音声の実効振幅で、端末の物理的な音圧や他アプリとの聴感比較ではありません。

| 条件 | 旧版に対するRMS | 新版ピーク（上限1） | クリップしたサンプル |
| --- | ---: | ---: | ---: |
| 通常BGM | 2.665倍 | 0.180 | 0 |
| 山場BGM | 2.671倍 | 0.211 | 0 |
| 既存効果音 | 2.742倍 | 0.130 | 0 |
| BGM＋密集した効果音・新爆発音 | 比較対象の音が異なるため倍率評価なし | 0.405 | 0 |
| 人工的な同位相16音ストレス | クリッピング確認用 | 0.654 | 0 |

0%とSOUND OFFは出力0を確認。BGMの40%は100%時の約0.4倍のRMSとなります。生データは [audio-render.json](measurements/audio-render.json)、再現試験は `audio-render.browser.test.cjs` です。実機のスピーカー・イヤホン・OS音量・聴感での最終確認は必要です。

## ノヴァの比較試算

同じ4本のseed（127/158/189/220）、無敵、通常の射撃だけを使います。通常機体、変更前ノヴァ、変更後ノヴァを比較します。敵・コア・ステージの数値を変えたり、隕石を強制削除したりはしません。開始カウント・3択の停止を除いたゲーム内時間です。

ステージでは横移動で敵を狙い、コアは威力/連射など攻撃優先で選びます。「初期」は初期強化なし、「標準」は弾速Lv.3・2発・ドローンLv.1。実際に全隕石を殲滅するまで進め、以下の全96試行がクリアしました。

| 通し番号 | 装備 | 通常機体（秒） | 旧ノヴァ（秒） | 新ノヴァ（秒） |
| ---: | --- | ---: | ---: | ---: |
| 5 | 初期 | 31.84 | 32.28 | 31.55 |
| 15 | 初期 | 33.94 | 34.65 | 35.05 |
| 25 | 初期 | 44.42 | 45.93 | 41.31 |
| 40 | 初期 | 60.04 | 63.07 | 52.55 |
| 5 | 標準 | 30.57 | 31.68 | 30.85 |
| 15 | 標準 | 32.04 | 32.30 | 32.49 |
| 25 | 標準 | 36.38 | 38.94 | 35.80 |
| 40 | 標準 | 44.97 | 47.83 | 40.64 |

最終40面の標準装備では通常44.97秒に対して新ノヴァ40.64秒（約9.6%短縮）、初期装備では60.04秒に対し52.55秒（約12.5%短縮）です。旧ノヴァより恩恵が出ています。一方、15面では通常より少し遅く、発射間隔の弱点が残っています。30秒の出現時間は短縮せず、殲滅部分が変わります。

エンドレスは180秒間の平均撃破数を比較します。「育成済み」は弾速Lv.5・3発・ドローンLv.3・威力2・連射3から始める人工的な高火力条件です。「往復移動」は狙いを合わせず左右と上下に動き、コアは最初の候補を選びます。

| 操作・装備 | 通常撃破数 | 旧ノヴァ撃破数 | 新ノヴァ撃破数 | 通常比 |
| --- | ---: | ---: | ---: | ---: |
| 狙い撃ち・初期 | 558.50 | 558.75 | 573.25 | +2.6% |
| 狙い撃ち・標準 | 558.50 | 557.00 | 571.25 | +2.3% |
| 狙い撃ち・育成済み | 561.00 | 557.75 | 571.00 | +1.8% |
| 往復移動・弾速Lv.2/2発/ドローンLv.1 | 224.25 | 216.25 | 292.50 | +30.4% |

狙い撃ちでは通常より約2%多い程度ですが、標準装備の画面内平均隕石数は4.52から3.23へ約29%減りました。往復移動では撃破数が約30%増え、横に散った敵への爆発の恩恵が大きくなります。これは意図する強化ですが、操作と密集度によって差が広がるため、強すぎないと断定するものではありません。特に低HPの密集と回避優先の遊び方は試遊で確認してください。数値は指定どおり暫定値です。

無敵の自動試算は火力と殲滅時間の比較で、人間の回避難度・継続率・面白さの実証ではありません。攻撃に狙いを合わせる場合は出現数が撃破数の上限にもなります。結果の生データは [nova-balance.json](measurements/nova-balance.json)、再現コマンドは `node star-dodge/tools/simulate-nova.cjs` です。

## 検証と互換性

- Node全127件成功（既存122件を維持、追加5件）。追加は弾ダメージ連動/上限・連鎖の各1回/深さ・殲滅と失敗優先の3件、各音のゲイン/圧縮経路・専用音/制限の2件です。
- 既存ブラウザ10本と新しい2本、計12本成功。PC1440×1000・スマホ相当390×844/360×640で爆発の描画・粒子・シェイク・音・演出軽減を確認しました。
- 音量の実ゲイン期待値をマスター1.0へ、音声ノード上限を51へ更新。爆発の旧半径70/固定1/非連鎖の期待値は新仕様へ書き換え、テストは削除していません。
- エンドレスの基準データは、通常/貫通/誘導の3機体についてPR-Aとの180秒一致を維持。ノヴァは強化が意図した挙動変更なので専用の新しい固定入力記録と比較し、旧データは履歴として残します。
- `cd star-dodge/mobile && npm run sync` 成功。13個のWebアセットがwww/Android publicへ一致して同梱されることを確認しました。
- 公開番号、アプリID、署名/ビルド設定、40面の定義はmainと一致。セーブ形式・報酬式・コイン価格は変更しません。ノヴァの撃破効率が上がるため、既存の破壊ボーナスの上限へ届きやすくなる可能性はあります。
- SWキャッシュだけを `star-dodge-shell-v0-5-0-nova-audio` へ変更。同じ0.5.0の古いキャッシュから、新しい一式へプレイを中断せず移行する試験も成功しました。
