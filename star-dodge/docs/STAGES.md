# 全10ステージと当たり判定

各ステージの制限は30秒。3秒の開始カウントと一時停止は含まず、HPを残して30秒に達するとクリアします。結果画面でコインを精算し、次ステージを解放。途中でホームへ戻る/最初からはクリア・精算しません。ちょうど30秒のフレームで致命傷を受けた場合は失敗を優先します。

ホームのステージカードから解放済みを選択できます。機体・初期強化・スキンは毎回適用し、HPと飛行中のアイテム強化は開始時にリセット。クリア済みは再挑戦できます。全10クリア後は最終クリア画面を表示し、ステージ10の再挑戦・ホームへ進めます。エンドレスは同じ選択画面から選べます。

速度には隕石種類別の倍率と乱数を掛けます。硬さhに対し、小型HP=h、中型HP=h+2、大型HP=2h+4。同時数は配置候補の最大で、隙間の確保や全体上限によって少なくなることがあります。各ステージの最初の出現は表の間隔後です。ステージ1→10へ向かい、速度と密度が上がり、硬さ・同時数も下がりません。数値の原本は `stages.js`。

0.5向け実装では、12秒・24秒に機体の近くへ追従する強化コアが出現します。生存中に取得すると停止して最大3択から1つを選びます。HP満タン時の修理、上限済みの強化は候補から外れ、候補が少ないときは枚数も減ります。全て上限なら余剰コア+2コインです（総報酬500まで）。アイテムを取っただけでSPEED等が自動上昇する方式は終了しました。

ステージ1–2で蛇行、3以降で予告付き突進、5以降で射撃が加わります。エンドレスは30/60/90秒から順に解放。既存のサイズ・HP・基本間隔・速度の表は維持し、特殊行動をその一部に割り当てます。

ステージ15秒には奇数ステージで5秒のラッシュ（間隔0.8倍、最短0.22秒）、偶数でエリート1体が出現。エンドレスは60秒ごとに交互です。新規出現はイベント開始時の機体位置付近を避け、隕石上限80を維持。エリートは半径42・HP=2h+6、金色の枠で示し、撃破すると確定コアを落とします。

被弾判定は全機体共通で**中心の半径6**（従来10）。面積は従来の36%ですが、隕石との衝突は双方の半径の合計で判断するため、被弾率が64%減るという意味ではありません。白い円の外周が判定と一致し、被弾後の無敵中は黄色で表示。機体が点滅しても判定円は消しません。翼の見た目は被弾判定に含みません。アイテム取得用の半径10と移動の端10は維持します。

クリア・ロック・初回報酬・重複防止は自動テスト済みです。実機や実ユーザーによる難易度の評価は未実施で、特に後半は初期強化との組み合わせを試遊して調整してください。
