# 8惑星・全40ステージと当たり判定

各ステージは最初の30秒が出現フェーズです。3秒の開始カウント・一時停止・強化選択中はゲーム内時間に含みません。30秒時点で生存中の隕石が残っている場合、殲滅フェーズへ移行し、すべて破壊するまで続きます。残敵が0なら、その時点で即クリアします。対象は通常/蛇行/突進/射撃/エリートの `rocks` 全体で、画面上から入ってくる途中や再出現待ちの隕石も含みます。

殲滅中は通常出現・山場・定期コアを停止し、新しい敵弾とエリート撃破コアも生成しません。既に飛んでいる敵弾は移動・被弾判定を続けますが、殲滅対象ではありません。既にあるコアは取得でき、3択中の停止も有効です。

下へ抜けた隕石は同じ個体を上へ戻し、残りHP・最大HP・種類を維持。xと速度は既存のseed付き乱数で再設定します。突進の予告などの行動状態は接近から再開します。殲滅中は衝突やシールド防御でも隕石を消さないため、よけ続けたり体当たりしたりするだけではクリアできません。

最後の隕石を撃破すると、既存の `gameover` / `cleared` 通知を1回だけ発行します。同じフレームにHPが0になれば失敗を優先。結果画面で終了までのゲーム内生存時間に基づくコインを精算し、次ステージを解放します。途中放棄/最初からではクリア・精算しません。エンドレスは出現・コア・イベント・敵弾・下抜けによる除去を含め従来どおりです。

ホームから「惑星リスト → その惑星の5ステージ」の2階層で解放済みを選択します。地球 → 水星 → 金星 → 火星 → 木星 → 土星 → 天王星 → 海王星の8チャプターです。通し番号は1〜40、惑星番号は `ceil(id / 5)`。ステージ名は惑星内の「ステージ1」〜「ステージ5」で、ホーム・HUD・結果は「地球 ステージ3」の形式です。未解放の惑星も閲覧できますが、ロック中のステージは選べません。

機体・初期強化・スキンは毎回適用し、HPとフライト中の強化は開始時にリセット。クリア済みは再挑戦できます。全40クリア後は最終クリア画面を表示し、海王星 ステージ5の再挑戦・ホームへ進めます。エンドレスは同じ選択画面から選べます。通し番号5（地球 ステージ5）でランス、15（金星 ステージ5）でノヴァ、25（木星 ステージ5）でシーカーが解放され、初回クリア結果で通知します。再挑戦では通知を繰り返しません。

## カーブの考え方

惑星内は小さく上げ、惑星境界で一段上げます。各惑星の5面目は間隔・速度の上昇幅を大きくし、HPもさらに+1。惑星が1つ進むと基本HPは+1、次惑星の1面目のHPは前惑星の5面目と同じ値から始まるため、HPは下がりません。小型HPをhとして、中型h+1・大型h+3・エリートh+5です。同時数は木星から2、海王星から3。画面内の上限は12から51へ、各面で1ずつ増えます。速度には既存の種類別倍率と乱数を掛け、各面の最初の出現は表の間隔後です。

原本は `stages.js`。惑星の0始まり番号をp、惑星内の0始まり面番号をsとして、`t = (5p + 0.7s + (s == 4 ? 0.35 : 0)) / 38.15`。間隔は `1.05 - 0.55t`（小数3桁）、速度は `65 + 95t`（小数1桁）です。HPが高くなった後半でも殲滅が長引きすぎないよう、HPと出現密度を合わせて調整します。

最終40面は速度160（旧10面155）、HP9/10/12（旧4/6/12）。間隔は0.5秒（旧0.32秒）へ広げ、画面内上限51（旧80）で密度を抑えます。間隔だけを旧10面より短くすると、惑星ごとのHP増加と重なって過度に硬くなるためです。配置・上限を無視した出現候補のHP合計は最終面で約57.6HP/秒、旧10面の約50.6HP/秒から約14%増です。これは実際に命中するHP量や難易度の測定値ではありません。

固定seed4本、通常機体、初期弾速Lv.3/2発/ドローンLv.1、攻撃優先のコア選択、横移動で狙う自動操作では、旧10面の平均43.64秒に対し40面は平均44.97秒で殲滅完了しました。全40面×seed2本の自動試験も、同じ初期火力で最後の隕石まで射撃で破壊できることを確認します。恒久強化なしの初期火力でも、同じ4本のseedの最終40面は56.23〜64.45秒で殲滅できました。無敵にして火力・殲滅時間だけを比較しており、プレイヤーの回避難度や楽しさを実証する試験ではありません。数値は試遊で調整する前提です。

エンドレスの `CONFIG`、出現間隔・速度・同時数・HP・上限80・火力は変更しません。従来の小型h・中型h+2・大型2h+4、エリート2h+6の式をそのまま使います。PR-Aマージ時点を原本とした4機体それぞれの180秒・固定seedの全フレーム比較で、定期コア・3択・敵弾・山場を含む挙動の一致を確認します。

0.5向け実装では、12秒・24秒に機体の近くへ追従する強化コアが出現します。生存中に取得すると停止して最大3択から1つを選びます。HP満タン時の修理、上限済みの強化は候補から外れ、候補が少ないときは枚数も減ります。全て上限なら余剰コア+2コインです（総報酬500まで）。アイテムを取っただけでSPEED等が自動上昇する方式は終了しました。

ステージ1–2で蛇行、3以降で予告付き突進、5以降で射撃が加わります。エンドレスは30/60/90秒から順に解放。ステージでは上表のHPと速度を使い、通常隕石の一部を特殊行動へ置き換えます。

ステージ15秒には奇数ステージで5秒のラッシュ（間隔0.8倍、最短0.22秒）、偶数でエリート1体が出現。エンドレスは60秒ごとに交互です。新規出現はイベント開始時の機体位置付近を避け、ステージでは表の隕石上限、エンドレスでは従来の上限80を適用。エリートは半径42で、HPはステージでは上表、エンドレスでは2h+6。金色の枠で示し、エンドレス、またはステージの出現フェーズ中の撃破では確定コアを落とします。

被弾判定は全機体共通で**中心の半径6**（従来10）。面積は従来の36%ですが、隕石との衝突は双方の半径の合計で判断するため、被弾率が64%減るという意味ではありません。白い円の外周が判定と一致し、被弾後の無敵中は黄色で表示。機体が点滅しても判定円は消しません。翼の見た目は被弾判定に含みません。アイテム取得用の半径10と移動の端10は維持します。

殲滅移行・出現停止・再出現・同時致命傷・実時間精算に加え、クリア・ロック・初回報酬・重複防止は自動テスト済みです。実機や実ユーザーによる難易度の評価は未実施で、特に後半は初期強化との組み合わせを試遊して調整してください。

HUDには殲滅中の残り隕石数を表示し、移行時に「TIME UP — 残りの隕石を殲滅せよ」のバナーと既存イベント音を出します。進行バーは30秒で満タンとなり、殲滅完了まで維持します。`stages.js` の `duration: 30` は出現フェーズの長さで、フライト全体の制限時間ではありません。
