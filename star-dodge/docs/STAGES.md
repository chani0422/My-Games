# 全10ステージと当たり判定

各ステージは最初の30秒が出現フェーズです。3秒の開始カウント・一時停止・強化選択中はゲーム内時間に含みません。30秒時点で生存中の隕石が残っている場合、殲滅フェーズへ移行し、すべて破壊するまで続きます。残敵が0なら、その時点で即クリアします。対象は通常/蛇行/突進/射撃/エリートの `rocks` 全体で、画面上から入ってくる途中や再出現待ちの隕石も含みます。

殲滅中は通常出現・山場・定期コアを停止し、新しい敵弾とエリート撃破コアも生成しません。既に飛んでいる敵弾は移動・被弾判定を続けますが、殲滅対象ではありません。既にあるコアは取得でき、3択中の停止も有効です。

下へ抜けた隕石は同じ個体を上へ戻し、残りHP・最大HP・種類を維持。xと速度は既存のseed付き乱数で再設定します。突進の予告などの行動状態は接近から再開します。殲滅中は衝突やシールド防御でも隕石を消さないため、よけ続けたり体当たりしたりするだけではクリアできません。

最後の隕石を撃破すると、既存の `gameover` / `cleared` 通知を1回だけ発行します。同じフレームにHPが0になれば失敗を優先。結果画面で終了までのゲーム内生存時間に基づくコインを精算し、次ステージを解放します。途中放棄/最初からではクリア・精算しません。エンドレスは出現・コア・イベント・敵弾・下抜けによる除去を含め従来どおりです。

ホームのステージカードから解放済みを選択できます。機体・初期強化・スキンは毎回適用し、HPと飛行中のアイテム強化は開始時にリセット。クリア済みは再挑戦できます。全10クリア後は最終クリア画面を表示し、ステージ10の再挑戦・ホームへ進めます。エンドレスは同じ選択画面から選べます。

速度には隕石種類別の倍率と乱数を掛けます。硬さhに対し、小型HP=h、中型HP=h+2、大型HP=2h+4。同時数は配置候補の最大で、隙間の確保や全体上限によって少なくなることがあります。各ステージの最初の出現は表の間隔後です。ステージ1→10へ向かい、速度と密度が上がり、硬さ・同時数も下がりません。数値の原本は `stages.js`。

0.5向け実装では、12秒・24秒に機体の近くへ追従する強化コアが出現します。生存中に取得すると停止して最大3択から1つを選びます。HP満タン時の修理、上限済みの強化は候補から外れ、候補が少ないときは枚数も減ります。全て上限なら余剰コア+2コインです（総報酬500まで）。アイテムを取っただけでSPEED等が自動上昇する方式は終了しました。

ステージ1–2で蛇行、3以降で予告付き突進、5以降で射撃が加わります。エンドレスは30/60/90秒から順に解放。既存のサイズ・HP・基本間隔・速度の表は維持し、特殊行動をその一部に割り当てます。

ステージ15秒には奇数ステージで5秒のラッシュ（間隔0.8倍、最短0.22秒）、偶数でエリート1体が出現。エンドレスは60秒ごとに交互です。新規出現はイベント開始時の機体位置付近を避け、隕石上限80を維持。エリートは半径42・HP=2h+6、金色の枠で示し、エンドレス、またはステージの出現フェーズ中の撃破では確定コアを落とします。

被弾判定は全機体共通で**中心の半径6**（従来10）。面積は従来の36%ですが、隕石との衝突は双方の半径の合計で判断するため、被弾率が64%減るという意味ではありません。白い円の外周が判定と一致し、被弾後の無敵中は黄色で表示。機体が点滅しても判定円は消しません。翼の見た目は被弾判定に含みません。アイテム取得用の半径10と移動の端10は維持します。

殲滅移行・出現停止・再出現・同時致命傷・実時間精算に加え、クリア・ロック・初回報酬・重複防止は自動テスト済みです。実機や実ユーザーによる難易度の評価は未実施で、特に後半は初期強化との組み合わせを試遊して調整してください。

HUDには殲滅中の残り隕石数を表示し、移行時に「TIME UP — 残りの隕石を殲滅せよ」のバナーと既存イベント音を出します。進行バーは30秒で満タンとなり、殲滅完了まで維持します。`stages.js` の `duration: 30` は出現フェーズの長さで、フライト全体の制限時間ではありません。
