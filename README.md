## STAR DODGE

隕石をよけて生存記録を伸ばし、機体と初期スキルを育てるPC・スマホ対応ゲームです。ホーム・チャレンジ・6種類のスキン・ライセンス・フライト履歴・PWAに対応。Androidの試用APKと未署名AABもビルド済みです。
